# ZCode 任务通知器安装

本技能只处理一次性的安装编排。它不会隐式触发，不会驻留，不会读取会话正文，也不会自行实现常驻监控循环；技能不承载常驻监控。

常驻通知只提交事件的首发自动化；不会根据 `sendmessage failed` 或 `context_token` 自动创建后续自动化。如需补发，必须由用户显式执行 `backfill --codex-thread`。

## 触发边界

- 只有用户明确输入 `/zcode-task-notifier-install` 或明确点名本技能时才执行。
- “帮我安装任务通知器”“配置微信”等泛化请求不触发本技能；先请用户显式输入上面的命令。
- 对技能本身，不要读取、打印、解密或上传任何机器人凭据、会话内容、日志或数据库副本。
- 技能本身不直接接触凭据值；外部只读检查仅校验本地加密凭据存在/前缀，但绝不解密、打印、上传或持久化凭据值。

## 必须按顺序编排

1. **微信机器人引导**：说明用户需要在 ZCode 的远程控制/机器人管理中新建微信机器人，用手机扫码确认，打开开关，并在微信中给机器人发一条消息完成激活。只检查配置存在、启用状态、激活状态、凭据引用和工作区授权，不接触凭据值。
2. **停下教学**：如果没有可用微信机器人、机器人未启用或未激活，停在教学步骤，不调用安装动作；请用户修复后回复“已启用”或“ready”。
3. **继续复检**：收到确认后重新运行只读检查。复检仍失败就再次停下，报告缺失条件并再次等待，不猜测配置，也不绕过机器人前置条件。
4. **是否同时监控 Codex**：微信检查通过后单独询问用户是否监控 Codex 任务，默认否。用户选择否时走 **仅配置 ZCode**，不读取 Codex 目录或状态。
5. 在用户选择明确后，调用仓库外部 `scripts/install.ps1`，把 `-EnableCodex` 或 `-DisableCodex` 传给它；安装器完成后仅调用 `doctor`，不要重复推进来源游标，并展示脱敏健康结果。

## 外部动作边界

外部安装器负责复制版本化程序、写入本机配置、迁移可验证的旧快照、创建当前用户的 Windows 计划任务、升级回滚和卸载。技能本身禁止注册计划任务、禁止启动常驻进程、禁止轮询来源，也不把监控逻辑放进技能目录。

如果没有可用的技能运行时，告知用户可以手动执行 `scripts/install.cmd` 或 `scripts/install.ps1`；交互安装仍需完成微信前置检查。非交互调用必须显式选择 Codex 开关。

## 停止与验证

真实端到端验证仍待用户在目标 ZCode 环境完成；静态检查和合成测试不能替代真实运行时验证。

安装器或 `doctor` 返回非零时停止并报告可操作的摘要；不要把“未观察到成功日志”当成发送失败。真实微信到达需要用户在本机观察，静态检查和合成测试不能替代它。
